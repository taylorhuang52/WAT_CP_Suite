CP Report Data 日期篩選工具

上傳 CP_Report_Data 的 JSON（或原始 .zip）檔案，設定日期後，會將該日期以前的資料從各資料表中移除，並產生新的 JSON 檔供下載。

1上傳資料檔案

2設定篩選日期

資料集內各資料表使用的日期欄位不同，本工具會自動依下列欄位判斷日期：
dailyRaw → Test Date（Excel 序列日期）／ watYieldRaw → runOn／ ulldYield → Test Date／ ulldDetail → Test Date／ stripRaw → Report Date
watRaw 本身沒有日期欄位，會依 lot 對應 watYieldRaw 篩選後仍存在的批號來決定是否保留；找不到對應批號的記錄會保留並標記為「無法判斷」。

3預覽篩選結果

資料表原始筆數移除保留無法判斷日期

4產生並下載新的 JSON
